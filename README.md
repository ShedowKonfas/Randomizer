# Randomizer

Консольный генератор случайного выбора: вы вводите список вариантов, скрипт называет один из них.

## Быстрый старт

```bat
python main.py
```

## Пример

```
Введите название раздела или нажмите на клавишу Enter чтобы закончить ввод: Кофе
Введите название раздела или нажмите на клавишу Enter чтобы закончить ввод: Чай
Введите название раздела или нажмите на клавишу Enter чтобы закончить ввод:
Выпадает: Чай
Для продолжения нажмите Enter, для выхода нажмите 0 или q для полного выхода:
```

## Как это работает

1. Ввод вариантов до пустой строки.
2. `random.choice()` выбирает один вариант.
3. Enter — новый выбор по тому же списку, `0` — ввести список заново.

## Структура

- `main.py` — функция `random_choice()` и её вызов;
- `random.ico` — иконка;
- `dist\Randomizer.exe` — уже собранный exe (spec-файла в репозитории нет);
- `README.md`, `AGENTS.md` — документация.

## Подводные камни

- Пустой список печатает `1`.
- `q` не завершает программу: вызывается `SystemExit()` без `raise`, поэтому цикл продолжается. Для выхода Закройте окно терминала.
- Импорты `tkinter` в `main.py` не используются.
- Тестов и `requirements.txt` нет.
