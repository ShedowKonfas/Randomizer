# AGENTS.md

Назначение: консольный случайный выбор из введённого списка; логика — в `random_choice()`.
## Карта файлов

| Файл | Роль |
|---|---|
| `main.py` | ввод вариантов, `random.choice()`, цикл продолжения |
| `random.ico`, `dist\Randomizer.exe` | иконка и готовый exe без spec-файла |
| `README.md`, `AGENTS.md` | документация |
## Запуск и проверка

`python main.py`.
Тестовой команды нет; не выдумывай тесты без запроса пользователя.
## Соглашения

- Подсказки в консоли и документация — на русском.
- Не добавляй GUI без запроса: закомментированный tkinter-код не используется.
## Подводные камни

- `q` не выход: `SystemExit()` создаётся, но не выбрасывается.
- `0` перезапускает ввод списка, пустой список печатает `1`.
- `build\` и `dist\` — артефакты, не удаляй их без разрешения.
